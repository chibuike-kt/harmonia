The JSON files in this directory are real Monaco editor theme
definitions from the monaco-themes npm package (MIT License), converted
from real, well-known community TextMate themes. Copied here as static
assets (not imported as a module) because monaco-themes's own package
exports don't expose its themes/ directory for direct import — the
intended usage for consumers of this package.

https://www.npmjs.com/package/monaco-themes
